A few details.

Before you open your first run.

Which agents does it support?

Claude Code and Codex local history, including supported Codex CLI and editor sessions. Cursor history is not supported yet. Planned MCP client compatibility is separate from reading an agent’s own history.

Does it need an account or API key?

No. The current viewer reads local transcript files. It does not call a model or upload your sessions. Installing the npm package requires access to the npm registry.

Does it change my session files?

No. Transcripts are read-only. Your notes, tags, pins, and preferences are stored locally in the browser. You can export sessions as Markdown or JSON.

Does a green tool call prove the task worked?

No. Runlens shows recorded activity. File changes are recorded operations, not a final Git diff. Usage and cost appear only when recorded; Codex token totals cover the main agent only.

Can I connect an agent through MCP today?

Not yet. The MCP roadmap starts with a safety contract, then bounded search and summary tools, then tested client setup. There is no announced release date.
